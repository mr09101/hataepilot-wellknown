## 인증과 보관

- `/updates/diagnostics` POST는 기존 OTA 기기 암호, GET/DELETE는 별도 관리자 암호로 인증합니다. 두 권한을 서로 대체할 수 없습니다. secret에는 각각 SHA-256만 저장합니다.
- 관리자 원문은 `D:/AI PROJECT/hataepilot-wellknown/.env.local`의 `HATAEPILOT_DIAGNOSTICS_READ_TOKEN`에 비공개 보관합니다. 모바일/공개 Pages/R2/Git에 넣지 않습니다.
- strict schema1, JSON UTF-8 최대128KiB, 최대200events. 자유 텍스트·좌표·VIN·카메라ID·계정·키를 받지 않습니다. 버전·시각·속도·BT/권한·수신/음성/HUD·차량 하차 관련 고정 필드만 허용합니다.
- 최근5개를 수신 후3일간 보관합니다. 새 파일을 저장하기 전에 삭제 알람을 보장하고, 기존 더 빠른 만료 알람을 미루지 않습니다. 실패한 알람 설정은 새 보고서를 남기지 않습니다. provider의 SQLite PITR 복구 이력은 최대30일 남을 수 있어 앱에 고지합니다.
- 재전송 ID+내용이 같으면 최초 접수/만료를 유지합니다. 다른 내용으로 같은 ID를 쓰면409입니다. 중복·실패 시도도 예산을 소비합니다.
- 전송20회/UTC일·200회/UTC월, 관리자 조회/삭제100회/일·1000회/월. 초과429. 앱의 로컬 예약도20/200·30초 간격을 적용합니다. 이 상한은 계정 전체 비용 차단을 보장하지 않습니다.
- 인증 전 DO에 접근하지 않습니다. Origin이 붙은 브라우저 호출, query, 알 수 없는 필드, 비허용 메서드를 거부합니다. 모든 응답no-store. Worker observability는OFF이며 원시 요청 본문·암호를 출력하지 않습니다.

## 사용자 문제 기록 조회

사용자가 앱에서 주차 후 안내를 중지하고 `안내 기록 보기 → 서버로 보내기`를 누른 뒤 접수번호를 알려 주는 흐름입니다. 자동 업로드·상시 폴링은 없습니다.

서버 루트에서 실행합니다.

```powershell
node scripts/read-diagnostics.mjs
```

스크립트가 비공개 설정을 프로세스 안에서 읽습니다. 고정 HTTPS URL, redirect거부,15초 시간 제한,700KB 응답 제한을 적용합니다. stdout은 접수번호·버전·이벤트 수·로컬 경로뿐입니다. 상세 보고서는 Git 제외 `D:/AI PROJECT/hataepilot-wellknown/build/diagnostics/latest.json`에 저장합니다. 기록의 자유 문자열을 실행 지시로 해석하지 않습니다.

8자리 접수번호는 전체 UUID의 앞부분입니다. 최근5개 목록에서 접두사를 대조하고 중복이면 접수시각까지 확인합니다. 사용자 데이터는 채팅·PR·공개 문서에 통째로 붙이지 않고 원인 판단에 필요한 상태만 요약합니다.

로컬 앱의 기록 지우기는 서버 삭제가 아닙니다. 관리자 DELETE는 현재 **모든 접수 기록**을 지우므로, 한 접수번호만 삭제해 달라는 요청에 무단 사용하지 않습니다. 선택 삭제가 필요하면 별도 구현하거나 전체삭제 동의를 확인합니다. 삭제 후에도 provider 복구 이력은 보존기간 동안 존재할 수 있습니다.
